---
title: "simpleaf workflow refresh"
---

`simpleaf workflow refresh` pulls the latest protocol estuary library from [its GitHub repository](https://github.com/COMBINE-lab/protocol-estuary). We recommend updating the registry everytime before fetching a workflow.

## Refresh Usage

The relevant options (which you can obtain by running `simpleaf workflow refresh --help`) are:

```sh
Update the local copy of protocol esturary to the latest version

Usage: simpleaf workflow refresh

Options:
  -h, --help     Print help
  -V, --version  Print version
```
